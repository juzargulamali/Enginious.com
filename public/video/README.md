# Showreel files (not committed by default)

Drop the approved showreel here and redeploy; the homepage hero switches to file mode automatically.

| File | Spec |
|---|---|
| `showreel.mp4` | 1920x1080, H.264, silent, a 15-30 s loop of the strongest footage, <= 12 MB |
| `showreel.webm` | optional VP9/AV1 version of the same |
| `showreel-mobile.mp4` | optional 1280x720 (or a 9:16 crop), <= 5 MB |
| `showreel-poster.jpg` | 1920x1080 still from the best frame |

Until then the hero plays the YouTube showreel (privacy-enhanced embed) behind the same poster and controls.
